Atomic Dev Tools

44 developer utilities in one fast web app, from JSON and JWT tools to cron and timezone helpers. 43 of them run entirely in the browser.

role
Sole developer
platforms
Web
kind
personal

The problem

Small, everyday jobs like decoding a JWT, formatting JSON, checking a CIDR range or converting a timestamp meant opening a slow desktop app or pasting tokens and API responses into an ad-heavy third-party site. I wanted one place with no load time, no account and no data leaving the browser.

The approach

  • A Next.js and TypeScript app in a Turborepo and pnpm monorepo, with a shared tool registry and a fixed set of nine categories.
  • 43 of the 44 tools run client-side, including bcrypt, Argon2, HMAC and JWT signing. The one exception is the port checker, which needs a server to open a TCP socket.
  • Heavy dependencies, such as a tokenizer of about 1 MB, are imported only by the page that needs them, so they don’t bloat the shared bundle.
  • The FFmpeg tools build commands rather than process video in the browser, which keeps the app fully static.
  • A generator command scaffolds each new tool with the same two-file pattern.

Where it is

Feature-complete and in daily use locally. Not deployed publicly yet.

Results

  • → 44 tools, 43 fully client-side
  • → Per-route code splitting for heavy dependencies
  • → A generator that scaffolds each new tool
