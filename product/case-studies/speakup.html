The write-up

The problem

Speaking practice works best as short, repeatable drills: a prompt, a time limit and a way to listen back. Most language apps need a connection, an account or a subscription before you can start.

SpeakUp works entirely offline, so a session is never held up by a connection, a login or a server.

The approach

  • Feature-based clean architecture across 11 features, with the presentation layer talking only to BLoC and domain entities, never to the data layer.
  • Storage picked per access pattern: ObjectBox for the 242-card deck, session history and custom categories; Hive for settings and challenge progress.
  • One codebase for Android, iOS, web and desktop. ObjectBox doesn’t run on the web, so a conditional import lets the web build fall back cleanly.
  • One GoRouter route tree drives a bottom bar on phones and a navigation rail on wider screens.
  • On-device audio recording and playback for self-review, with no network calls anywhere in the core app.
  • BLoC logic tested with bloc_test and mocktail.

Where it is

In active development; not in the stores yet.
